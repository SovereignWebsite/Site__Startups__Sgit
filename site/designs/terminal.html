“Git for encrypted vaults, for humans and AI agents”

sgit lets people and AI agents clone, commit, branch and merge folders of files that are encrypted on their own machine before upload. The server holds only ciphertext, and a one-way read key lets anyone open a vault without an account.

what-it-is.txt

sgit is a command-line tool for folders of files that are encrypted with AES-256-GCM on your own machine before they are uploaded. You clone, commit, branch, diff and merge them much as you would with git.

The server stores only ciphertext under opaque IDs. It never sees filenames, file contents or commit messages.

A vault can be handed to someone with a single read key: no account, no hosting and nothing for the reader to install. The same vault opens in a browser through SG/Vault.

The code is free under Apache-2.0. What is sold is the running, maintained hosted service, at sgraph.ai; self-hosting is documented. sgit is marked beta.

who-it-is-for.txt

  • AI agents and the people working with them: agent state that must outlive the context window, shared between agents, with a human reviewing merges.
  • Professional services such as legal, M&A, audit and security assessment, handling client working documents.
  • Health and regulated sectors, where a host that provably cannot read the content changes what is allowed.
  • Not for everyone: if your files are not sensitive, the site says to use git and a private repository.

Sources: 1, 4, 5

components.txt

  • sgit ↗

    The command-line tool: pip install sgit-ai. Pure Python, Python 3.11 or newer, two runtime dependencies, Apache-2.0.

  • SG/Vault

    A web app to browse and edit vaults and run their apps in the browser, an independent implementation of the same wire format.

  • SG/Send

    The zero-knowledge storage and transfer API both clients speak to, hosted by sgraph.ai or self-hosted.

  • Published vaults ↗

    A catalogue of vaults with public read keys: 54 when last updated on 13 October 2026.

  • SGit Newsroom ↗

    Articles, a newsletter and a reading meter, at its own address since October 2026.
