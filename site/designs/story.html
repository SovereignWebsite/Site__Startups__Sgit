The story of

sgit

sgit lets people and AI agents clone, commit, branch and merge folders of files that are encrypted on their own machine before upload. The server holds only ciphertext, and a one-way read key lets anyone open a vault without an account.

sgit starts from one sentence on its own site: "you have files that need version control and collaboration, and the place they are stored must not be able to read them."4

The package first appears on PyPI as version 0.8.17 on 20 March 2026. Releases came quickly through the spring, with more than thirty a month in April and May.13

In August 2026 the project's own site began, at version 0.1.1 on 11 August, and the first published vaults followed on 16 August: real work shared openly with read keys.9 10

By 13 October 2026 the site listed 54 published vaults and around 4,000 tests, and the SGit Newsroom had moved to its own address, newsroom.sgit.ai. Version 0.27.0 reached PyPI on 28 October 2026.10 1 9 13

The site is candid about what it is not. It says it is in "daily production use by its authors, a small n", and tells anyone whose files are not sensitive to use git and a private repository instead.4

How it works

  1. A folder becomes a vaultAn ordinary folder gains a .sg_vault directory. A commit snapshots the whole folder; there is no staging area.2 6
  2. Encrypted on your machineEvery commit, tree and blob is encrypted with AES-256-GCM before upload, with keys derived by PBKDF2 at 600,000 iterations.2 7
  3. The server sees ciphertextObjects are stored under opaque IDs. The server can see sizes and timing, never names or contents.2 7
  4. One string opens itThe vault key is address, credential and root of every key. A one-way read key decrypts but cannot write, so it can be published.2 4
  5. Merge, in terminal or browserEach machine or agent gets a private branch; shared branches merge three ways. The browser app speaks the same format.1 6

What it offers

  • sgit

    The command-line tool: pip install sgit-ai. Pure Python, Python 3.11 or newer, two runtime dependencies, Apache-2.0.8 3

  • SG/Vault

    A web app to browse and edit vaults and run their apps in the browser, an independent implementation of the same wire format.3

  • SG/Send

    The zero-knowledge storage and transfer API both clients speak to, hosted by sgraph.ai or self-hosted.3

  • Published vaults

    A catalogue of vaults with public read keys: 54 when last updated on 13 October 2026.10

  • SGit Newsroom

    Articles, a newsletter and a reading meter, at its own address since October 2026.11 9
